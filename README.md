# Thilan Portfolio

An immersive personal portfolio built with **Node.js (Express)** and **Three.js**.

## Quick start

```bash
npm install
npm run dev
```

- Frontend (Vite): http://localhost:5173
- API server: http://localhost:3000

## Production

```bash
npm run build
set NODE_ENV=production&& npm start
```

Open http://localhost:3000

## Stack

- Express API + static hosting
- Vite frontend tooling
- Three.js interactive hero scene
- Custom motion, typography, and layout
